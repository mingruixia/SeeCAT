质量控制

质量控制在 Preprocessing 和 fMRIPrep denoising 中自动完成；QC reports 页用于查看结果并决定使用哪些 run。

单个 run 的报告

每个 run 有一个 sub-*/…_desc-qc_report.html，内容包括：

  • 概要：帧数、去掉的帧、平均和最大 FD、被标记的帧、保留的分钟数、tSNR、去噪前后 FD 与 DVARS 的相关（去噪效果好时接近 0）、最大平动和转动、覆盖率；
  • 头动：FD 随时间的变化（标出阈值和被标记的帧）、平动和转动曲线；
  • 去噪前后的 DVARS；
  • 去噪前后的 carpet 图（Power 2017），体素按灰质、白质、脑脊液排列；
  • 配准与覆盖：叠加模板灰质轮廓和脑 mask 的标准化平均 EPI，以及配准指标；
  • 用于提取干扰信号的白质和脑脊液 mask；
  • 图像质量指标（MRIQC）。
{{IMG qc_run_report.png | 单个 run 报告的一部分：概要、头动和 DVARS。}}

图像质量指标（IQM）

开启 qc.iqm（默认）时，Preprocessing 复用自己的分割、头动校正和配准结果，在原始数据上计算 MRIQC（Esteban et al. 2017）的指标：BOLD 用去掉前几帧、经头动校正、未做层间时间校正的 run；T1 用其偏场校正图和个体空间组织图。基于公式的指标与 MRIQC 自身函数在相同输入上的结果一致；头部、空气和脑区 mask 由 SeeCAT 自己生成，因此绝对值可能与实际运行 MRIQC 的结果有出入。请在同一数据集、同一中心内比较各 run。

覆盖率

每一帧都在视野内的模板脑比例，包括总体，以及分别计算的脑顶部（z > 50 mm）和底部（z < −30 mm：小脑和颞极）。覆盖率低说明部分脑区没有扫到。

Seed FC

基于种子点的功能连接。对每个 run 和每个种子点，计算种子点体素（有信号的体素，使用剔除后保留的帧）的平均信号与结果 mask 内每个体素的相关（Mask：默认为脑 mask，也可选灰质或 mask 文件；见下文“掩膜”），写出 Pearson r 图和 Fisher z 图（z = atanh r）。Harmonize 和 Statistics 请使用 z 图。

{{IMG fc_page.png | 两个球形种子点（PCC 和 mPFC）的 Seed FC。表格中球形和 mask 可以混合；Check 列显示某行还缺什么。}}

种子点

  • 球形：MNI 毫米坐标的中心（x y z）和半径；中心周围半径内的体素。例：PCC 0 -53 26，mPFC 0 52 -6，左侧运动皮层 -38 -22 56。
  • Mask：MNI 空间的 NIfTI 图像（任意体素大小，大于 0 的体素即种子点），以最近邻方式重采样到数据。Add mask files 为每个选中的文件添加一行，并以文件名命名。

名称只能是字母和数字，会成为输出图的 desc。

{{PARAMS fc Input|Seeds|Maps}}

掩膜

Seed FC、Degree 和 Gradients 共用一个选项 Mask mode（掩膜方式）（mask_mode），决定分析 mask（Mask；Gradients 为节点）如何与每个 run 的脑 mask 结合：

  • 在各 run 脑 mask 内（run，默认）：mask 限制在该 run 自己的脑 mask 内，因此不同 run 的体素会因视野和分割略有差异。
  • 在组 mask 内（group）：只用所有入选 run 的脑 mask 都包含的体素，每个 run 的体素完全相同。组 mask 写在输出目录的 group/masks/ 下，其 .json 列出所用的 run；增减 run 会改变组 mask，结果随之重新计算。覆盖差的 run 会让所有人的组 mask 变小，请先查看 QC 报告。
  • 按原样（given）：使用 mask 的全部体素，不与任何脑 mask 求交集，例如为全组制作的 mask。Mask 须为灰质或 mask 文件（不能是脑 mask）。在某个 run 的脑 mask 或视野之外，去噪后的序列为 0：这些体素在结果图中为 0（Gradients 不把它们计入节点平均），每个 run 的日志会给出其数量。

JSON sidecar 记录所做的选择：Mask、MaskMode、GroupMask（使用组 mask 时为其文件），Degree 另有 VoxelsWithSignal。

当分析 mask 在计算图的范围内没有任何体素（例如 mask 文件处于另一空间；种子体素不计入），或剔除后剩余帧数少于“最少帧数”（min_frames，默认 50）时，该 run 失败，不写出任何图（Gradients 则把该 run 排除，并在日志中列出）；错误信息给出体素数或帧数。最少帧数是硬性下限；哪些 run 被建议排除，仍由 QC 的有效数据时长规则（censor.min_minutes，5 分钟）决定。

Degree

体素水平的度中心性。mask 中的每个体素都是该 run 相关网络（使用剔除后保留的帧）的一个节点。体素的二值度是相关达到阈值的连接数；加权度（强度）是这些连接 r 值之和。与 SeeCAT 1.0 的定义相同：由 z 分数化后的序列计算相关，按正负规则处理（absolute 取 |r|，negative 取 −r），低于阈值的置 0。可选择忽略短于某距离的连接，或按距离分段（短程和长程度中心性）。网络由哪些体素构成取决于 Mask 和 Mask mode（见 Seed FC 下的“掩膜”）。结果图以原始值和 mask 内 z 分数（在有信号的体素上计算）两种形式写出，可选再平滑（网络由未平滑的数据构建）。

时间和内存随体素数的平方增长：3 mm 时灰质约 5 万个体素，每个 run 几秒到一分钟；2 mm 时体素数是其 3.4 倍，计算量超过 10 倍。

Gradients

连接梯度（Margulies et al. 2016）：连接模式在皮层上变化的主要轴线，第一梯度通常从感觉运动皮层延伸到默认网络。对每个 run：

  1. 节点信号：每个节点（更粗的 MNI 网格中的体素，或图谱分区）内该 run 脑 mask 体素的平均（按 Mask mode，也可以是组 mask 体素，或 mask/图谱中有信号的体素；见 Seed FC 下的“掩膜”），使用剔除后保留的帧；
  2. 连接矩阵：节点间的 Pearson r；
  3. 每行只保留最强的 10%（稀疏度 0.9），其余置 0；
  4. 行与行之间的亲和度：归一化角度（余弦相似度对应夹角的 1 − 角度/π）或余弦；
  5. 扩散映射嵌入，α = 0.5（Coifman & Lafon 2006），多尺度特征值 λ/(1−λ)，与 BrainSpace（Vos de Wael et al. 2020）相同；

然后对齐各 run（广义 Procrustes：通过旋转和翻转对齐到参考，再把参考更新为平均，最多 10 轮），首次参考为组平均连接矩阵的梯度（默认）或第一个 run 的梯度。SeeCAT 求解的是该问题的对称形式，得到的嵌入是精确的扩散映射。

Harmonize

多中心研究的每张图都带有中心和扫描仪差异。Harmonize 在计算指标（Seed FC、Degree、Gradients、VBM）之后、统计之前，从被试图中去除这些差异，同时保留你要检验的效应。校正后的图写在原图旁边，desc 标签加上后缀（desc-PCC → desc-PCCComBat）。

{{IMG harmonize_page.png | 实例中 PCC 图的 Harmonize：中心列、ComBat，以及要保留其效应的协变量。}}

方法

方法做什么适用情况
combat参数化经验贝叶斯 ComBat（Johnson et al. 2007；Fortin et al. 2017, 2018）：每个体素的数据 = 中心位置 + 协变量效应 + 按中心缩放的误差；逐体素估计中心的位置和尺度，并在体素间收缩，然后去除。默认；小中心可以从收缩中获益
combat_nonparam不假设中心效应分布的经验贝叶斯（先验取自最多 5000 个其他体素）中心效应明显偏离正态时
combat_noeb逐体素估计位置和尺度，不做收缩大中心
combat_mean只校正中心均值方差需要保持不变时
combat_gam非线性协变量以固定自由度（Spline df）的自然三次样条进入模型、用最小二乘拟合的 ComBat。思路与 ComBat-GAM（Pomponio et al. 2020）相同，但 neuroHarmonize 拟合的是带惩罚的 GAM，因此结果与它不完全相同年龄跨度大、存在非线性效应
covbatComBat 之后再去除体素间协方差的中心差异（Chen et al. 2022）各中心的网络结构不同时
lm线性回归：在含协变量的模型中去除中心均值简单的参照方法

各种 ComBat 的结果与 neuroCombat 一致。可以指定一个参考中心保持不变，其他中心向它校正。之后要检验的效应都必须列在要保留的协变量中；否则，在其中心间分布不同的部分，会和中心效应一起被去掉。日志和 group/harmonize<label>_<maps>_<hash>/…_report.json（hash 用于区分不同的图选择）给出校正前后存在中心效应（F 检验 p < 0.05，控制保留的效应）的体素比例。

中心样本较小时。combat、combat_nonparam、combat_noeb、combat_gam 和 covbat 的尺度（方差）校正会用每个中心自己的标准差去除该中心的残差。每个中心人数少时，这些估计噪声很大，校正后的数据看起来比实际变异更小，后续对保留协变量的检验因而偏于宽松（Nygaard et al. 2016）。在实例 B 中（3 个中心各 10 人，年龄为模拟值），对 ComBat 校正后的 VBM 图做灰质–年龄回归，得到 3 个实际并不存在的簇；用 combat_mean、lm，或不做校正而把中心作为协变量，都没有簇。每个中心少于约 20 人时，SeeCAT 会在日志和报告中给出警告。此时建议使用 combat_mean 或 lm，或不做校正、在 Statistics 中把中心列作为协变量；报告结果前请与未校正的结果对照。

Statistics

对被试图做组统计：逐体素一般线性模型、对比和多重比较校正。模型、平滑度估计和随机场理论都与 SPM 一致，因此同一模型的结果与 SPM 结果表相同。

{{IMG stat_page.png | 单样本实例的 Statistics 页：按文件名字段选择被试图，设计和校正方法。}}

设计

设计问题需设置默认对比
one_sample平均图是否不为 0？–pos、neg
two_sample两组是否不同？Factor：participants 列；LevelsAgtB、BgtA
paired每个被试两张图（如 ses-1、ses-2）Factor：取值不同的实体两个方向

协变量会去均值；文本协变量转为去均值的哑变量列。Variance 为 unequal（anova1_rm 的默认）时，与 SPM 一样用 ReML 估计非球形性。

多重比较校正

  • cluster_fwe（默认）：超过团块形成阈值 p（0.001）的体素组成团块，按随机场理论，团块大小的 FWE p < alpha 时保留。
  • voxel_fwe：FWE p < alpha 的体素（随机场理论）。
  • voxel_fdr：错误发现率 < alpha 的体素（Benjamini–Hochberg）。
  • tfce_fwe：无阈值团块增强（Smith & Nichols 2009；E = 0.5，H = 2，26 邻接），体素 FWE p 由置换检验得到（Freedman–Lane：单样本为符号翻转，配对设计为被试内交换，其他为行置换），与 FSL randomise 相同。并行 worker 分担置换计算。

勾选 Two-tailed（默认）时，每对 t 对比中的每一个以 alpha/2 检验。被 QC 剔除的图不参与分析；因缺少 participants.tsv 行或缺失值而去掉的图都会在日志中列出。

Viewer

查看器可在 MNI 脑上显示任意 NIfTI 图像：SeeCAT 的统计图、种子点图、度中心性图、梯度图、VBM 图，或四维 BOLD 序列。

{{IMG viewer_ortho.png | 查看器中的单样本 PCC 结果：三个视图、带图谱标签的光标信息和团块表。}}
  • 布局：Orthogonal（三个视图和光标信息）、Single（一个大视图和三个缩略图）、Mosaic（同一方向的多张切片）。
  • 底图：按图的空间自动选择（IXI549Space 用 ch2，MNI152NLin2009cAsym 用 ICBM152 2009c），也可从下拉框选择。
  • 阈值：按数值或按 p 值。对 SeeCAT 的统计图（以及头信息中有自由度的 SPM 风格统计图），p 阈值可以做校正（cluster FWE、voxel FWE、voxel FDR），使用与 Statistics 相同的代码，因此查看器与统计结果一致。还可设置方向（+、−、±）、最小团块大小、颜色和不透明度。
  • 团块：团块表列出峰值和图谱标签（SPM 自带的 Neuromorphometrics；安装 BrainNet Viewer 后还有 AAL 和 Brodmann）；点击某行，光标移到该处。Export TSV 保存团块表。
  • 时间序列：对四维序列，显示光标处体素的信号以及 FD 和被标记的帧；滑块和 Play 逐帧浏览。
  • Save image 把当前视图存为 PNG；Save map 把阈值化后的图存为 NIfTI；Surface 在 BrainNet Viewer 中把图显示到皮层上。
  • Neuro / Radio：左脑显示在左边，或在右边。
