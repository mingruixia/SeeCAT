各模块详解

本章每节介绍一个页面：用途、原理、全部选项（表格由软件本身生成，与窗口中的选项完全一致）、读写的文件，以及脚本用法。标有 高级 的选项需勾选 Show advanced options 后才显示。多个页面共用的选项（去噪、剔除、质量控制、输出、选择、运行）集中在 6.12 至 6.15 节介绍。

Import to BIDS

把现有数据整理成 BIDS 数据集。源文件夹可以是 DICOM 文件，用内置的 dcm2niix 转换；也可以是 NIfTI 图像，按原样整理。NIfTI 图像可以是扫描仪或影像平台导出的带 .json 说明文件的数据，也可以是没有说明文件的旧 .nii、.nii.gz 或 .img 数据。SeeCAT 自动识别被试、扫描次数和图像，为每张图像拟定 BIDS 名称；写入任何文件之前，都可以先修改这些名称。源文件夹只读不改。

使用步骤

  1. 填写 Source folder（源文件夹）和 BIDS folder（目标文件夹）。BIDS 文件夹必须在源文件夹之外。Subject、Session 和 Rules 先留空。
  2. 点击 Preview names，不写任何文件。Log 显示识别出的目录结构（例如 subjects from folder names at level 1 (e.g. sub173_zhangsan → sub-173)）。Summary 表格每张图像一行，列出被试、session、序列号、序列描述、来源路径、拟定的 bids 名称和说明：如何命名的，或为何不整理。
  3. 检查 bids 列。要改名，直接修改路径；要不整理某张图像，清空它。单带参考像（sbref）会随所属的 BOLD run 一起改名，run 被清空时它也一并去掉。
  4. 点击 Convert，按表格当前内容整理。
  5. 点击 Save as rules，把核对过的名称存为规则文件并填入 Rules。之后 Preview 和 Convert 会对每个被试按同样的方式命名，可以用它整理整个研究的数据。

如何识别被试、session 和图像

  1. DICOM 还是 NIfTI。文件夹下（derivatives 之外）有 NIfTI 图像时按 NIfTI 整理，否则转换其中的 DICOM 文件。
  2. 被试（NIfTI）。SeeCAT 依次尝试：
    1. sub-<label> 文件夹。
    2. 名称都像编号的最浅一级文件夹。这类名称含数字，且不是日期、session 名称，也不是 07_rest 这样的序列文件夹。这一条覆盖每个被试一个文件夹（S001/…）、先按模态再按被试（FunRaw/S001、T1Raw/S001），以及按扫描次数和序列导出的结构（sub173_zhangsan/2026-10-13T11_09_18/functional/07_…）。
    3. 文件名开头的编号（S01_rest.nii）。
    4. 说明文件中的 PatientID。
    5. 源文件夹本身的名称。
    标签只保留编号，去掉编号后面的姓名（sub173_zhangsan → 173，S_001 → S001）。其他结构可以用 'subject_pattern' 指定一个含一个捕获组的正则表达式，例如 'Subj_(\d+)'。
  3. 被试（DICOM）。SeeCAT 读取每个含 DICOM 文件的文件夹中第一个和最后一个文件。PatientID 相同的文件夹属于同一被试，被试名取自包含此人全部文件夹、且不含他人文件夹的那一级。PatientID 缺失或已匿名化时按目录树判断。一个文件夹的第一个和最后一个文件属于不同的人时报错。
  4. Session。名为 ses-<label>、pre、post、baseline、followup、visit1、v1、t1 等的文件夹直接给出 session。否则按扫描次数分组，依据是说明文件或头信息中的 study，或日期文件夹。只扫描一次的被试不设 session 文件夹；多次扫描按日期依次为 ses-1、ses-2 ……，对应关系保存在 code/seecat/from_dicom_sessions.tsv，以后新的扫描得到下一个编号。
  5. 命名。第一条匹配的规则给图像命名（见下文的 Rules）。默认规则把三维 T1 加权像（MPRAGE、SPGR、BRAVO 等）命名为 anat/…_T1w，把静息态 BOLD（序列名含 rest、rsfMRI 或独立的 RS）命名为 …_task-rest_bold。没有规则命名的图像按以下方式识别：
    • 任务态 BOLD：二维 EPI，至少 20 帧。任务名取自去掉末尾编号的序列名，末尾编号作为 run：Math_AI_trust3 → task-mathaitrust_run-3。BOLD、EPI、MB 等扫描术语不进入任务名。
    • 场图：序列名含 fieldmap、fmap、B0 map、topup 或 SE-EPI。梯度回波场图命名为 magnitude1、magnitude2 和 phasediff，并由两张幅值图写入 EchoTime1、EchoTime2。自旋回波 EPI 场图命名为 epi，dir-AP、PA 等取自序列名或相位编码方向。
    • 单带参考像（SBRef、…_SB1，单个体积）：命名为同一次扫描中紧随其后、层面网格相同的 BOLD run 的 sbref。
    • 弥散像：带 .bval/.bvec 的图像命名为 dwi。
    • 不整理（原因写在说明中）：定位像、相位图和衍生图像；以及 T1 未做畸变校正的副本（ImageType 含 ND），前提是校正后的那份也在。其他图像只列出，不复制。
  6. Run、echo 和 IntendedFor。同一 session 中名称相同的多个序列按序列号依次为 run-1、run-2 ……；同一序列的多个回波为 echo-1 等。一组场图供它之后、下一组场图之前采集的 BOLD run（及其 sbref）使用，这些 run 以 bids:: 路径写入场图的 IntendedFor。
  7. 没有说明文件的图像：序列描述取自文件夹和文件名，帧数和 TR 取自图像头。图像头中没有 TR 时，用 'tr' 选项给出。同一文件夹中带编号的三维图像（f0001.nii、f0002.nii ……，不少于十个），只有文件名末尾的编号不同时，视为一个 run，写成一个四维图像。S01_rest_0001.nii 与 S02_rest_0001.nii、run1_vol0001.nii 与 run2_vol0001.nii 属于不同的 run。编号不连续，或图像的网格、方向、TR 不一致时不合并，并给出警告说明原因；此时请把每个 run 的图像放到单独的文件夹，或先合成四维图像。Analyze 格式的 .img/.hdr 写成 NIfTI。
  8. 写出。
    • 图像以 .nii.gz 及其说明文件写到 sub-<label>/[ses-<label>/]anat|func|fmap|dwi。
    • 说明文件复制时去掉姓名、ID、出生日期等可识别个人身份的字段。保留下来的文本字段（SeriesDescription、ProtocolName 及嵌套字段）和无说明文件图像的描述中，也会去掉被试姓名。姓名的来源有三处：PatientName；被试文件夹名中编号后面的词（sub173_zhangsan）；文件名开头编号后面、其他被试的文件中都没有的词（sub173_zhangsan_rest.nii 与 sub174_lisi_rest.nii 并存时）。其他写法的姓名（zhangsan_173，或与其他词连写）无法识别，其他自由文本也原样保留，共享数据集前请检查报告和说明文件。participants.tsv 加入该被试；说明文件中有相应信息时，同时写入 sex 和扫描时的 age。
    • 缺少 dataset_description.json 时会写出。
    • 已在数据集中的图像保留，因此重新整理只补充缺少的部分。
    • 每张图像的去向记录在 code/seecat/from_nifti_sub-<label>.tsv（DICOM 为 from_dicom_…）。表中被试文件夹或文件名开头的编号显示为 sub-<label>，按上述方式识别出的姓名不出现在路径和描述中。原始路径只出现在窗口 Preview names 的表格和 seecat.bids.from_nifti 返回的表中，不写入数据集。

脚本中还有以下选项：

  • 'dryrun', true：只返回整理计划，不写文件。
  • 'names', P：使用修改过的计划（表格或 TSV 文件）。
  • 'auto', false：只按规则命名。
  • 'tr', 2：为没有 TR 的 BOLD 指定 TR。
  • 'link', true：同一磁盘上的 .nii.gz 图像用硬链接代替复制，节省空间，但数据集与导出数据共用这些文件。
  • 'subject_pattern'：用正则表达式从路径中取出被试标签。

每条规则用正则表达式（不区分大小写）匹配说明文件字段，给出 datatype、suffix 和实体；或用 "skip": true 表示不整理。除说明文件字段外，还可以匹配 Path（图像在源文件夹中的位置）和 Volumes（帧数）。第一条匹配的规则生效。

Data check

预处理之前，先看看数据集里有什么。Data check 列出 BIDS 数据集（或 derivatives 文件夹）中每个 BOLD run 的帧数和 TR；如果有混杂变量表（预处理或 fMRIPrep 之后），还给出平均和最大帧间位移，以及被标记为高头动的帧。平均 FD 超过 0.25 mm 或超过 20% 的帧被标记的 run 会高亮显示。Open in viewer 逐帧查看所选 run 及其头动曲线；QC report 打开它的质量报告。

Preprocessing

用 SPM 预处理 BIDS 数据集中的每个 BOLD run，把可直接分析的数据写到 derivatives/seecat。每个 run 是一个单元；它的 T1 像（有 session 时优先同一 session）用于配准和分割。

{{IMG prep_page.png | 实例的 Preprocessing 页：输入、预处理、VBM、去噪和质量控制卡片。}}

处理步骤

  1. 输入。把 run 和它的 T1 复制到工作文件夹，并去掉开头信号未稳定的帧：dummy_scans = auto 时，在前 20 帧中，全脑平均信号相对整个 run 的中位数和 MAD 为稳健离群值（z > 3.5）的开头连续帧被去掉；扫描仪已丢弃的帧不会重复计算。
  2. 层间时间校正（SPM）。各层采集时间取自 sidecar 中的 SliceTiming（秒），因此顺序、隔层和多带采集都能正确处理；除非另行设置，参考时刻为 TR 的中点。层时间按 SliceEncodingDirection 解读（缺省为 k；k- 会反转为体素顺序）。层沿第一或第二体素轴（i、j）的数据不受支持，运行会报错停止；请先调整图像方向，或关闭层间时间校正。
  3. 头动校正（SPM）。两轮：先对齐到第一帧，再对齐到平均像。六个头动参数写入混杂变量表；数据在这一步不重采样。
  4. 配准。用归一化互信息把 T1 配准到平均 EPI（只修改其头信息）。
  5. 分割。用 SPM 组织概率图对 T1 做统一分割，得到个体空间的灰质、白质、脑脊液图，偏场校正后的 T1，以及到 IXI549Space 的形变场。没有 T1 时（normalise.method = epi）改为分割平均 EPI。
  6. 干扰信号 mask。在被试自身空间中取白质（p > 0.99）和脑脊液（p > 0.95）mask，用 2 mm 的球腐蚀，使其远离灰质；再重采样到输出网格。
  7. 标准化。把形变场一次性应用到 BOLD 数据（4 阶 B 样条，这是数据唯一的一次重采样）和组织图上，按所选体素大小写在 SPM 边界框内。
  8. 输出空间的 mask：脑 = 灰质 + 白质 + 脑脊液 > 0.5，且每一帧都在视野内。
  9. 混杂变量。与 fMRIPrep 同名的列：24 个头动回归量（6 个参数及其导数和平方；Friston 1996），帧间位移（Power 2012），全脑（global_signal）、白质和脑脊液的平均信号，白质和脑脊液的 aCompCor 成分（在好的帧上计算），每个被标记的帧一个 motion_outlier_XX 列，以及 censor 列。
  10. IQM（可选，默认开启）：原始 BOLD 和 T1 的 MRIQC 图像质量指标，见 6.5 节。
  11. 去噪。每个体素一个线性模型：多项式趋势（1 阶）加上所选回归量，数据和回归量用同一个滤波器带通，在好的帧上拟合。高头动帧先用好的帧插值填补（频谱插值），避免滤波把尖峰扩散出去；拟合时不使用它们，并为后续步骤做标记。最后把体素均值加回。输出：desc-denoised。
  12. 平滑（可选）：所选 FWHM 的高斯核；输出 desc-denoisedSm6。未平滑的序列保留。
  13. 写出结果，并为每个 run 生成 QC 报告；全部 run 完成后生成组报告和剔除列表。
为什么先去噪再平滑，为什么回归量也要滤波。在平滑后的数据上回归干扰信号，会混入邻近组织的信号；只对数据带通而不对回归量带通，会把已去除的信号重新引入（Hallquist et al. 2013；Lindquist et al. 2019）。SeeCAT 对两者都滤波并一起拟合。高头动帧在滤波前插值，否则尖峰会扩散到相邻帧；插值得到的帧不会被后续统计使用（Power et al. 2014）。

fMRIPrep denoising

用于已经过 fMRIPrep 预处理的数据。对所选空间中的每个 BOLD run，读取 *_desc-preproc_bold、它的脑 mask 和混杂变量表，去掉 fMRIPrep 标记的非稳态帧，用 SeeCAT 自己的规则替换 fMRIPrep 的头动离群列（所有输入使用同一个 FD 规则），然后按与 Preprocessing 完全相同的方式去噪、剔除和平滑。输出文件名也相同，因此 Seed FC、Degree、Gradients 和 Statistics 的用法不变。这里不计算 IQM（fMRIPrep 的输出中没有原始数据）；头动、覆盖率和配准检查照常进行（如果存在 fMRIPrep 在输出空间的组织图，配准检查会使用它们）。
