# Doc

| Path | What it is |
|---|---|
| `manual/` | The SeeCAT 2.0 user manual, English and Chinese (`index.html`; PDFs in the release). Sources and build script in `manual/src`. |
| `design/` | Design notes of SeeCAT 2.0 (batch API, statistics, GUI, ...). They record decisions as they were made; the manual describes the current behaviour. |

| `description.docx` | **Historical:** the description of SeeCAT 1.x (four modules, structural connectivity, the DPABI-based workflow). It does not describe SeeCAT 2.0 and is not part of the release. |
